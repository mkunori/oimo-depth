# 恒久DEPTH・地層・掘削研究（#30）

SCOREは芋の累計、DEPTHは設備の掘削能力による距離です。深度・補償端数・購入済み掘削研究を `PermanentProgress` に置き、通常転生・全3段階の突破・深層解析で保持します。SCORE・芋を深度へ変換せず、DEPTHを転生や突破の必須条件にしません。ROOT REBIRTH・装備・掘削優先の自動購入は未実装です。

## 採用した計算と値

```
basePower = 0.025 + Σ(設備台数 × digPowerPerUnit)
digMultiplier = 2^(基本掘削ランク + 地脈掘削ランク)
linkMultiplier = depth >= 10000 ? 1 + 0.1 × 連携組数 : 1
digSpeed = basePower × digMultiplier × linkMultiplier / 現在の硬さ
```

芋の収穫スキル・地層収穫学・地脈共鳴・設備の芋マイルストーンは、この掘削式には乗算しません。芋の価格・生産・上限・研究効果は従来どおりです。自動購入の方針も芋生産の増分を使い続けます。全設備が掘削力を持ち、0台でも基礎0.025があるので、すべての地層で正の速度になります。

報酬は図鑑・研究・掘削補助の解禁だけです。芋・転生ptの受取ボタンや加算はなく、恒久の到達深度から導出するため二重付与しません。連携補助は現在の連携組数から毎回算出し、乗算結果を保存して重ねません。転生で設備が0になると連携補助だけは0組へ戻りますが、到達記録は維持します。

研究は各3ランク、1ランクごと掘削力×2、両方最大で×64です。基本は100mで解禁し1万/10万/100万芋、地脈は1kmで解禁し1000万/1億/10億芋。所持芋だけを消費し、SCOREを減らしません。永久に保持し、返金・自動購入・周回ごとの買い直しはありません。芋生産の「地層収穫学」とは別の研究です。SCORE上限中は既存の設備/研究と同様に購入を止めます。

## イベントと精度

`advanceWithAutomation` は従来どおり、設備購入・SCORE上限・残り時間を比較します。その固定設備の区間内で、DEPTHは次の地層境界と残り時間の早い方まで進み、硬さを切り替えます。10kmの掘削連携補助も到達時刻から適用します。外側の金額加算を細分化しないので、深度追加によって既存の芋の丸め・購入時刻を変えません。境界は最大5個で、秒数に比例したループにしません。

SCORE上限へ届く区間では、残SCORE÷芋生産速度で実際の稼働時間を求め、その時間だけ掘ります。上限到達後の待機時間、ゼロ秒、自動購入だけの時刻ではDEPTHを増やしません。同時刻の上限と購入は従来どおり上限が優先です。通常転生や突破でSCOREが再び稼働すれば掘削も再開します。

深度はGameNumberではなく、0〜1e12mの有限numberです。補償加算の `depthRemainder` は符号付きの丸め債務で、絶対値を `max(1, depth) × 32 × Number.EPSILON` 以下に制限します。`adjusted = speed × seconds - carry`、`next = depth + adjusted`、`nextCarry = (next - depth) - adjusted` とし、表示する深度は減らしません。境界では到達値へ揃え、端数を0にします。丸めが境界そのものを表現する場合は、その1ULP未満の端数だけを破棄します。芋の購入資金へ加える補正ではありません。

通常の分割/24h比較は絶対1e-6m以下、対象レンジ全体では絶対1e-6mまたは相対1e-12を許容します。SCORE上限・台数・ランクは従来どおり厳密に検証します。非有限・範囲外・未到達研究・過大端数を拒否し、数値範囲を超える進行は候補を破棄して停止します。1e12mは保存表現の対応範囲で、ゲーム内の到達上限や突破条件ではありません。

## 表示と保存v10

採掘欄にDEPTH・m/s・現在の地層/硬さ・次の境界までの距離を表示します。遠い未到達の地層・報酬・研究はDOM/ariaを含め非表示で、次の発見だけ？？？と予告します。10mから図鑑、100mから掘削研究を折り畳みで表示します。図鑑は実到達した名前だけを並べ、未発見分を件数へ含めません。現在の地層は恒久深度から導出するため、転生後も発見済みの名前が残ります。区間中に新しい境界へ達したときだけ軽量通知し、読込済みの履歴から再通知しません。

v10は `permanent.depthMeters` / `depthRemainder` / `digResearchRanks: {basic, vein}` を必須保存します。SCORE・所持芋は引き続きGameNumberの正規形文字列です。v1〜v9は既存の資産・権限・スキル・研究・自動設定・保存時刻を検証して維持し、深度0・端数0・掘削研究0を補います。昔どこまで掘ったかは推定しません。通常の復帰精算では、その保存時刻から最大24hだけ新式を適用します。すでにSCORE上限の旧保存は深度0のまま停止します。

書込失敗・破損・競合では既存の保護を使います。移行書込に失敗した元文字列もそのままエクスポートできます。掘削研究は候補の保存成功後だけ確定します。入出力の確認にDEPTHを表示し、インポートでは追加の放置報酬を与えません。初期化はDEPTHと掘削研究も削除することを明示します。

強化なしでも根脈層へ、任意強化で根源領域記録へ進めます。通常転生で深度を失わず、再開直後は設備0になるので速度が低下しますが、購入済み研究の×64は残ります。1分の強化あり経路は転生後の次の判断まで106995.593mへ進み、深度と研究の持越しを確認しました。6h/12hの判断は1e5以上の次回確認であり、放置中にはSCORE1e6で停止するため、1e5ちょうどの時刻と混同しません。ROOT自体を実行した結果ではありません。

研究ありは確認時に所持芋で購入する方策です。開始時のまとめ買いは、実画面で上限停止中に自動購入OFF→突破/研究→ONとする操作を、所要時間0で理想化しています。放置中に研究を自動購入したことにはしません。
