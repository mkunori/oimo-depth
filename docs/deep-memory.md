# 深層記憶（#37）

SCORE 1e9から1e12へ進む深層解析に、強化スキルの部分リセットを追加しました。解析の累計は恒久進行 `deepResearchCount`、当周回の再購入制限は `postDeepResearchSkillLock` に分離します。1e6→1e9の突破、通常転生報酬、設備・研究の価格や効果、SCORE上限は変更しません。

| 解析後の累計 | 保持枠 | 保持する強化スキル |
| --- | --- | --- |
| 1回 | 0/3 | なし |
| 2回 | 1/3 | 豊かな収穫 |
| 3回 | 2/3 | 豊かな収穫＋設備の目利き / 旅立ちの蓄えを確認画面で選択 |
| 4回以降 | 3/3 | 全3種類 |

保持は種類単位で、現在の全ランクを残します。未取得なら0のままです。3回目は既定の選択を設備の目利きとし、実行前なら変更できます。選択はその解析の引数であり、次の周回に不要な選択フラグは保存しません。常に豊かな収穫を先に保持し、残る強化スキルの前提を満たします。

## 解析の取引と再購入

解析時だけ累計を1増やし、保持枠外をランク0に戻して、そのランクまでに使った転生ポイントを全額返還します。収穫3・目利き2・蓄え1なら6＋3＋1＝10ptです。使用済み＋未使用のポイント総額は不変で、新しいポイントは発生しません。

機能解禁型の心得・自動設備管理と深層解析権を保持します。SCORE・所持芋・開始支給額・設備・研究ランク・自動設定・計算端数・進行時間も保持し、上限だけ段階2へ進みます。収穫倍率と次の設備価格は直後から新ランクを使い、過去の設備代を請求しません。

累計1〜3回の解析後は、失った種類やランク数にかかわらず、当周回の全強化型スキル購入を止めます。累計4回以降はリセットもロックもありません。通常転生は累計・権限・残ポイント・取得ランク・自動設定を保持し、ロックを解除します。購入時の前提は常に通常どおり判定するため、収穫0から目利き等を買うことはできません。将来の上位転生も、周回初期化を使う場合はこのロックが解除される境界です。上位転生自体は未実装です。

セッションは操作前に経過を旧倍率で精算し、候補の保存が成功してから回数・スキル・ポイントを公表します。キャンセル・二重クリック・同周回再実行・保存失敗・タブ競合で解析を重ねません。

## 履歴を考慮した検証とv8

- v8では非負の安全な整数 `permanent.deepResearchCount` と真偽値 `postDeepResearchSkillLock` を必須で保存します。巨大数の正規形文字列はv7と同じです。
- v1〜v7の資産・設定・日時を保持し、研究権限trueなら累計1、falseなら0に移行します。ロックはfalseで、既存スキル・支給額を遡って変更しません。正確な過去回数は推定しません。次の新規解析から累計2回のルールを適用します。
- 旧版はリセットできなかったので、v1〜v7を元の取得前提で検証した後に移行します。前提を満たさない旧セーブを、解析済みという理由だけで救済しません。
- 現行の恒久解禁権は、正の解析履歴がある場合に限って現在の強化前提の不足を許可します。ランク上限・最低転生回数・強化型同士の前提・ポイント収支は維持します。解析履歴は研究権限と一致し、初回取得に5転生必要なため `count - rootRebirthCount <= max(0, prestigeCount - 4)`、総ポイントは最低10pt（自動権限ありなら11pt）を要求します。ROOTも周回終了として数えることで通常転生なしの再解析を可能にし、段階2以上では当ROOT周回で新しい解析が必要です。ROOT未実行の旧保存は従来と同じ上限です。履歴なしの権利前提不足、負数・小数・過大回数を拒否します。[ROOT仕様](root-rebirth.md)を参照してください。
- ロックtrueは段階2かつ累計1〜3回のみ。保持枠外のランクが残る不整合も拒否します。累計3では目利き・蓄えの両方を残せません。累計2〜3の段階2でロックfalseは拒否し、累計1・ロックfalseの既存段階2だけ旧仕様からの引継ぎとして受理します。署名のないローカル保存だけでは、実在しうる履歴を偽装した編集までは判別できません。
- `runStartingImo` は実際の支給履歴です。ロック中の正規解析済み周回だけ、現在の蓄えランクを超えた過去の支給を許容します。現行最大100芋・50芋刻み、残高上限は引き続きSCORE＋支給額です。それ以外は現在のスキルボーナス以下の従来検証を維持します。

移行書込失敗・不正値・競合時の元テキスト退避と、24h精算・二重精算防止は [保存仕様](save.md) のままです。

## 初回解析後の再校正

既存シミュレーターの18研究比較は、初期状態から正規の権限取得・1e9到達を経由して初回解析を行います。収穫3/目利き1を失い7pt返還、収穫倍率×2.5→×1・割引10%→0%、当周回の再取得なしで比較します。返還ptは芋購入に使えません。

地層収穫学優先の1e9→1e12追加時間と、その区間の設備購入台数をmain `62d9a55` と比較：

| 1分 | 手動 | 27→115分 | 81→97 |
| 1分 | 自動 | 21→51分 | 53→53 |
| 6h | 手動 | 12→12時間 | 137→88 |
| 6h | 自動 | 6→6時間 | 70→70 |
| 12h | 手動 | 24→24時間 | 148→127 |
| 12h | 自動 | 12→12時間 | 70→70 |

1分手動の全行程は4時間57分→6時間25分、自動は2時間31分→3時間1分です。6h/12hの到達観測回数は変わりませんが、途中の到達時刻・待機・所有台数は変化します。全18ケースが1e12へ到達し、新設備2種を購入できました。1分方策は両研究ランク3、6h/12h自動は確認時の地層ランク1で到達します。詰まりはなく、価格・生産の追加調整は行いません。#29はこの新しい到達状態を基準に調整します。

これは方策別の観測値で、最適解やプレイヤー全体の平均ではありません。既存の初期方策・初回突破・設備・自動購入の経路は変更せず、v6固定基準も研究区間以外では引き続き厳密な回数・台数比較を行います。固定ファイル自体は更新しません。研究の差分は本仕様による意図的変更で、数値表現の誤差ではありません。

少数の重点検証として、既存テストを更新し、1〜4回の連続解析、3回目の両選択、返還・履歴支給・権限・ロック解除、v7移行と不正履歴、新v8往復、確認UIの選択を確認します。既存の保存失敗・競合・キャンセル・二重実行テストを流用します。
