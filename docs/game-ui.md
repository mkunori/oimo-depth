# 最小ゲーム画面

`src/App.tsx` が状態を採掘画面と設備一覧に渡します。PC は2カラム、900px 以下は1カラム、480px 以下では設備の購入ボタンも縦配置です。SVG 線画と CSS のみを使用します。

- `src/features/mining/MiningPanel.tsx`: 所持芋、収穫速度、累計 SCORE / 上限、ゲージ、状態、次の目標。
- `src/features/shop/Shop.tsx`: 所有数、現在倍率を含む1台の効果、次の価格、購入倍率と購入見積もり。×10 で買える台数が不足していても、実際に買える数量を表示します。既存3設備は現在の台数倍率と次の目標を、追加2設備はロックと解禁する上限段階を表示します。
- `src/features/mining/useMiningGame.ts`: 状態と採掘タイマー。初期状態・生産量・価格・購入数量・収穫更新はすべて既存コアを利用します。
- `src/features/prestige/PrestigePanel.tsx`: 転生報酬と確認ダイアログ、基本スキルの前提・費用・次の効果。スキルは PC で3列、900px 以下で1列です。

## 時間と購入

250ms 間隔のタイマーで `performance.now()` の実経過秒数を渡します。コールバックが遅れても固定の250msとして処理しません。購入時には直前の更新からの時間を購入前の生産能力で精算し、その後に購入します。

時間・購入・保存は UI から独立した `GameSession` が担当します。React の state updater の中では時計参照や保存を行いません。effect の cleanup でタイマーとイベントを解除するため、StrictMode の effect 再実行や再描画で多重登録しません。

SCORE 上限に達すると実収穫速度は0となり、設備の生産能力を補足表示します。画面・コアとも設備購入を停止し、クリック直前に上限に達した場合も購入前の精算で判定します。上限ゲージ・生産停止・設備解禁は現周回の `getScoreCap(state)` を使います。転生はSCORE100,000から手動実行でき、権利取得済みの1e6上限では、採掘欄の限界突破と通常転生を別操作で選べます。詳細は [転生](prestige.md)・[初回限界突破](breakthrough.md) を参照してください。

進行は localStorage に自動保存します。非表示中は通常の更新を停止扱いにし、復帰時に最大24時間分を一度だけ精算します。破損や他タブの変更を検出した場合は進行と購入を止めて案内します。詳細は [保存とオフライン進行](save.md) を参照してください。

## 表示と操作

設備欄の「自動購入」を開くと全体ON/OFF・3方針・設備別設定・指定優先順を設定できます。未取得・保存停止中はfieldset全体を無効にし、取得条件とロック理由を表示します。直近の自動購入台数は過剰に通知せず表示だけを更新します。全体OFFの初期設定、保存成功後の適用、手動操作直前の旧設定精算、設定の転生後保持は [自動購入](automation.md) を参照してください。

桁区切り、小数1桁まで、10億以上は科学表記（小数2桁まで）です。表示値は切り捨て、未到達の購入残高や SCORE を繰り上げません。丸めた値はゲーム計算には使いません。

台数倍率は小数5桁まで表示し、累積 ×1 / ×1.1 / ×1.265 / ×1.58125 と次の目標10 / 25 / 50台を区別します。購入で節目を越えたときは `role="status"` の短い達成メッセージを表示します。一括購入で複数の節目を越えた場合はまとめて通知し、読込時には再通知しません。設備所有数から効果を復元します。転生・インポート・初期化で通知をクリアします。

深層掘削機と芋精製プラントは段階0で「未解禁」と上限1E9条件を表示し、全購入倍率で無効にします。段階1では通常設備と同じ購入UIになります。採掘欄の限界突破確認はリセットなし・SCORE付与なし・権利必須を説明し、取消・Escape・フォーカス復帰に対応します。1e9では「地層研究」へ案内し、別の確認操作で1e12へ無料突破します。新設備2種は段階2で解禁し、研究倍率込みの効果を表示します。研究パネルで条件・各強化・返金を表示し、保存確認中/上限到達時は無効化します。1e12より先は未実装と明示します。転生後は上限1e6・全設備0台・研究強化0に戻り、両突破の権限と自動購入設定は維持されます。

購入倍率はラベル付きの標準 radio を使い、Tab・矢印キーで選択できます。購入ボタンは Enter / Space で実行できます。操作対象は44px以上、フォーカス枠を表示します。購入不可の理由は各ボタンの説明に関連付けています。

SCORE ゲージには label を設定し、上限到達は色に加えて文章で通知します。常時変化する数値は読み上げを止め、状態文だけ `role="status"` で通知します。
