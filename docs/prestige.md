# 初期転生と基本スキル（v0）

## 転生のルール

`src/core/prestige.ts` の `getPrestigeReward` / `prestigeGame` は、現在の周回の累計収穫 `runEarnedScore` だけで判定します。所持芋を設備購入で消費しても報酬は減りません。

| 現在の SCORE | 転生 | 報酬 |
| --- | --- | ---: |
| 100,000 未満 | 不可 | 0pt |
| 100,000 以上、1,000,000 未満 | 可能 | 1pt |
| 1,000,000 以上 | 可能 | 2pt |

初期上限は1,000,000です。#20の [初回限界突破](breakthrough.md) で同じ周回の上限を1e9へ拡張できますが、通常転生の報酬は1〜2ptのままです。解禁値・報酬は `PRESTIGE_BALANCE` に集約しています。時間の成長曲線は [シミュレーター](balance/README.md)、設備効果は [設備マイルストーン](equipment-growth.md) を参照してください。

## リセットと恒久データ

`GameState` を `RunState` と `PermanentProgress` に分離しています。

| 範囲 | フィールド | 転生時 |
| --- | --- | --- |
| 周回 | `imo`, `runEarnedScore`, `equipmentCounts`, `runStartingImo` | 設備・累計は0、残高と支給額は取得済スキルによる開始値 |
| 周回 | `scoreCapStage` | 0（上限1e6）に戻る |
| 周回 | `researchRanks` | 両研究0に戻る |
| 周回 | `postDeepResearchSkillLock` | 通常転生でfalseに戻る |
| 恒久 | `permanent.deepResearchCount` | 解析実行でのみ増加し、転生で維持 |
| 恒久 | `permanent.deepResearchUnlocked` | 研究権限を維持、再到達時の再突破は無料 |
| 恒久 | `permanent.prestigeCount` | 1増加 |
| 恒久 | `permanent.unspentPoints` | 報酬を加算 |
| 恒久 | `permanent.skillRanks` | 維持 |

周回スコアがリセットされるため、同じ周回の報酬を連続で取得できません。将来の実績などは `PermanentProgress` に追加する境界とし、今回未確定のデータは先行実装しません。

## スキル定義と仮バランス

ID・前提ランク・最低転生回数・ランク費用・最大ランク・効果種別を `src/data/skills.ts` に定義しています。自動転生・上位転生・装備のノードは未実装です。

| ID / 名前 | 前提 | ランク費用 | 最大 | 効果 |
| --- | --- | --- | ---: | --- |
| `harvest` / 豊かな収穫 | なし | 1 / 2 / 3pt | 3 | 基礎生産と設備生産の合計に、1ランクごと +50%（×1.5 / ×2 / ×2.5） |
| `discount` / 設備の目利き | 豊かな収穫ランク1 | 1 / 2pt | 2 | 設備価格10% / 20%割引 |
| `startingImo` / 旅立ちの蓄え | 豊かな収穫ランク1 | 1 / 2pt | 2 | 次の転生後の初期所持芋50 / 100 |
| `breakthrough` / 限界突破の心得 | 収穫3・割引1・転生5回以上 | 3pt | 1 | 今周回SCORE1e6で上限1e9へ突破する恒久権利 |
| `automation` / 自動設備管理 | 収穫1・転生1回以上 | 1pt | 1 | 表示中・放置中の設備自動購入を設定可能。取得時OFF |

収穫と割引は購入直後から適用します。初期所持芋は次の転生から付与し、現在の残高へ遡って加算しません。支給額は `runStartingImo` に記録し、**SCORE には加算しません**。残高の制約は `0 <= imo <= runEarnedScore + runStartingImo` です。収穫で増える残高と SCORE は同量、開始時の支給を使って設備購入でき、開始額を元に転生ポイントを得ることはできません。

生産・価格の適用は既存コアに集約しています。設備価格は `ceil(basePrice * priceMultiplier ** ownedCount * equipmentPriceMultiplier)` です。割引後に各台を切り上げ、一括購入でも個別購入と一致します。ボーナス付き価格は `getEquipmentPrice(id, ownedCount, state.permanent)` を使ってください。

`getSkillPurchase` は必要ポイント・次ランク・購入不可理由を返します。`purchaseSkill` はポイント不足・前提未充足・最大ランクでは入力をそのまま返します。不明なID・負数・小数・非有限のランクやポイントは例外です。保存データは、ランク範囲・前提・転生回数に対する獲得可能ポイント（支出済みを含め1回あたり1〜2pt）の整合性も検証します。

深層解析では強化型（収穫・割引・蓄え）を保持枠に応じてリセットし、使用ポイントを返還します。機能解禁型（心得・自動管理）は保持します。通常転生は解析累計を保持し、当周回の強化型再購入制限を解除します。取得時の前提と既存権利の存続、旧仕様の引継ぎは [深層記憶](deep-memory.md) を参照してください。

## 確認 UI と保存

「転生とスキル」に解禁 SCORE・報酬差・リセット対象・残ポイント・前提・現在と次の効果を表示します。転生はネイティブ `<dialog>` で確認し、キャンセルと Escape で取り消せます。上限到達後も転生して次の周回に進めます。確認から実行までの経過時間で報酬が1pt→2ptに変わった場合は、最新の報酬で再確認を求めます。

`GameSession` が操作直前に時間を精算し、候補状態の書込に成功してから進行を置換します。保存に失敗した場合は周回やポイントを失わず停止・案内します。転生・スキル購入は即時保存し、StrictMode や連続クリックで二重報酬を与えません。セーブ管理の「初期化」は恒久データもすべて消す別操作で、確認文に明記しています。

## 保存互換（現在 v8）

保存キー `oimo-depth.save` は維持します。#13でv2と恒久データ、#19でv3と上位設備、#20でv4と周回上限段階・突破権を追加しました。v1〜v3の既存値を保ち、段階0・心得0を補完します。v1は開始支給0・恒久データ未取得を補い、v2以降の既存スキル・転生回数・残ポイント・開始支給を維持します。移行後に通常の24時間上限で放置報酬を精算します。

v2以降は既存恒久データの欠落を許さず、v4は段階・基本4スキル、v5は全5スキル・自動設定を必須とします。#23のv5移行を経て、#24は旧v1〜v5へ研究権限false・研究0・新設備0を補うv6移行を追加しました。破損を旧形式として復旧しません。エクスポートはv8、インポートは検証済みv1〜v8を追加放置報酬なしで復元します。自動設定と研究権限は転生で保持し、計算端数と研究強化は消去します。[保存仕様](save.md)・[自動購入](automation.md)・[地層研究](research.md) を参照してください。

## 検証

コアでは報酬境界、リセット、二重請求防止、費用/前提/最大ランク、同時間の増収、割引の一括購入一致、支給芋と SCORE の分離を確認します。保存・セッションテストでは移行・復帰・入出力と書込失敗時の保護を、UI テストでは確認/取消・即時表示・次周回・永続性を検証します。ブラウザで実際のモーダル操作と PC/スマホ幅を確認します。
