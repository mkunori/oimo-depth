# 地層研究・第2突破（#24）

初回突破後にSCORE 1e9へ到達し、「地層研究」の深層解析を確認して実行すると、転生せず同じ周回の上限が1e12になります。費用は無料です。残高0でも確実に突破でき、SCORE・所持芋・設備・スキル・転生回数・自動購入設定・計算端数を保持します。SCOREを加算・消費しません。

## 権限と周回の境界

段階表は `src/data/scoreCaps.ts` の0:1e6、1:1e9、2:1e12です。0→1は既存の「限界突破の心得」と `performBreakthrough`、1→2は `performDeepResearch` の別操作です。段階1かつSCORE1e9でだけ後者を実行でき、上限到達前・二重実行は入力状態を返します。自動購入はどちらも実行しません。

解放した権限は `permanent.deepResearchUnlocked`、現在周回の上限は `scoreCapStage`、強化ランクは周回の `researchRanks` に分けます。通常転生は上限1e6、設備0、強化ランク0へ戻し、研究権限・心得・他スキル・自動設定を保持します。再び1e6で初回突破し、1e9で研究突破すれば、追加費用なしで同じ段階へ戻れます。通常転生の報酬は最大2ptのままです。

1e12では収穫・設備購入・研究購入・振り直しを停止します。さらに先の突破、上位転生、装備は未実装です。

## 採用した研究と設備

研究強化は段階2に入ってから所持芋で手動購入します。ランクは各0〜3です。

| 研究 | ランク1 / 2 / 3の価格（芋） | 効果 |
| --- | --- | --- |
| 地層収穫学 | 50,000,000 / 200,000,000 / 800,000,000 | 全生産に2^ランク、最大8倍 |
| 地脈共鳴 | 100,000,000 / 500,000,000 / 2,000,000,000 | 新設備2種だけに2^ランク、最大8倍 |

全生産は `(基礎1 + 既存設備の生産 + 新設備の生産 × 共鳴倍率) × 転生スキル倍率 × 地層倍率`。設備の生産は所有数・台数マイルストーン込みです。効率方針の限界生産量と設備一覧の1台表示も同じ研究倍率を使います。

上限到達前なら「研究強化を振り直す」で全ランクを0にし、価格表の支出総額を所持芋に全額返却します。SCOREは変わりません。返金を重ねて資金を増やせず、試し直しの費用もありません。恒久の研究権限は取り消しません。通常転生は支出を返却せず周回をリセットします。

| 新設備 | 基礎価格 | 台数価格倍率 | 基礎生産/秒 | 台数マイルストーン |
| --- | ---: | ---: | ---: | --- |
| 地脈抽出機 | 100,000,000 | 1.20 | 500,000 | 10/25/50台で×1.1/1.15/1.25を乗算 |
| 芋濃縮炉 | 1,000,000,000 | 1.25 | 8,000,000 | なし |

抽出機は突破時の資金で買える立ち上がりと台数育成、濃縮炉は高額・高生産の次の目標です。共鳴は新設備の投資効率を変え、地層収穫学は既存設備にも即効性があります。研究を買わなくても設備だけで進めます。2ノードに留め、配分を返金可能にすることで購入のやり直しを認めます。段階0/1では両設備・研究強化とも購入不能で、既存数値は変更していません。

## 成長比較と採用理由

`npm run simulate` は実コアの通常転生・権利取得・初回突破・1e9到達・保存復元・無料研究突破を通した18ケースを生成します。手動経路は自動購入スキルを一切取得しません。各経路内で同じ突破直後状態から研究0・地層優先・共鳴優先を比較します。自動/手動の取得経路と開始設備は異なります。方策の比較であり、最適解や全プレイヤーの平均ではありません。

| 確認間隔 | 設備購入 | 新設備のみ（研究0） | 新設備＋研究（地層優先 / 共鳴優先） |
| --- | --- | ---: | ---: |
| 1分 | 手動 | 122分 | 27分 / 27分 |
| 1分 | 自動・収穫効率 | 70分 | 21分 / 21分 |
| 6時間 | 手動 | 12時間 | 12時間 / 12時間 |
| 6時間 | 自動・収穫効率 | 6時間 | 6時間 / 6時間 |
| 12時間 | 手動 | 24時間 | 24時間 / 24時間 |
| 12時間 | 自動・収穫効率 | 12時間 | 12時間 / 12時間 |

上限だけ拡張・生産固定なら、手動1分経路の同じ開始生産から約903.4時間、自動1分経路では約539.0時間です。この値は購入を含む実測と分けた解析的な対照です。研究＋設備で手動1分の最終生産は開始の約99,936倍（地層優先）、約77,453倍（共鳴優先）でした。これは追加購入の効果も含み、研究単独の倍率ではありません。

低頻度では操作時刻の差が隠れます。手動6h・地層優先は1e12で約5時間59分50秒待機、自動6hは約5時間24分32秒待機します。放置中に研究を購入したことにはせず、ONの6h/12hでは最初に買えた地層1だけで進みました。1分方策は両研究ランク3へ進みます。地層/共鳴の優先順で最終台数・停止待ちが異なり、確認周期で有利不利も変わります。一意の最適解は主張しません。

1000倍の上限に合わせ、研究と新設備で短い購入周期の再加速を作る仮値として採用しました。1分経路で追加21〜27分は既存の1e9までの87〜220分より短い区間です。段階2を新要素の導入区間とし、長期の待ち時間の追加を避けています。将来の第3段階では再調整が必要です。

[比較CSV](balance/generated/research.csv) は突破まで・突破後・総時間、各設備数、研究ランク、生産増分、停止待ち、固定生産対照を含みます。[時系列CSV](balance/generated/research-timeline.csv) は確認・研究購入・自動設備購入・上限到達時刻を記録します。[図](balance/generated/research.svg) は1分方策のSCORE曲線です。既存15初期方策・5突破経路・12自動取得経路の到達時間はmainと一致します。

## 保存・数値精度・負荷

現行はv6。v1〜v5は新設備0・研究ランク0・研究権限falseを追加します。v5の全体ON/OFF・方針・旧5設備のフラグと優先順を保持し、新設備は個別ONで末尾へ追加します。全体OFFは維持し、段階2未満は個別ONでも買いません。v5設定の欠落・重複を既定値で隠しません。v6は全7設備・全5スキル・研究権限・両ランク・全7設備の自動設定が必須です。

無権限段階2、前段階未到達、段階1以下での新設備所有/研究強化、不正ランク・数値・残高を拒否します。権限trueには従来の心得の前提が必要です。旧形式での段階2は拒否します。書込成功後に候補状態を公表し、失敗・タブ競合では元の状態とセーブを保持します。インポートでは追加の放置報酬を与えません。

1e12は `Number.MAX_SAFE_INTEGER` 以下で、整数価格・台数は安全に扱えます。SCOREと残高には小数があるため浮動小数点の完全一致は保証せず、段階0/1の既存許容差0.001芋を維持し、段階2の一括/小分け比較は絶対差0.01芋、台数・ランク・設定は一致とします。既存の補償加算・価格境界の端数返済・上限優先を共通使用します。手動購入は不足額が小さくても購入不可です。

1回の自動精算の上限1024購入は維持します。最大割引20%・1e12と開始支給100を予算に、次価格が予算以下の台数を設備ごとに独立に数えた保守的上限は183/128/94/74/56/52/32、計619購入です。実際には全設備で予算を共有するためさらに少なくなります。テストでも全7設備の上限合計が1024未満と確認します。秒刻みではなく購入イベントだけを処理し、超過時は例外で元セーブを保護します。

1e15以上では残高の小数精度、ULP幅、価格の切上げ、補償端数の許容幅、台数/価格上限を再検討します。次段階を増やす前に、整数最小単位＋BigInt・十進数・仮数指数表現のどれを採るかを決め、保存形式・UI丸め・シミュレーターを一緒に移行する必要があります。本Issueでは先の上限を定義しません。
