# 恒久装備・SCORE支出（#33）

初回ROOTの実行後、装備に利用可能SCOREを一度だけ支払って恒久解禁します。全解禁品は常時有効で、スロット・OFF・モード・プリセットはありません。通常設備の `equipmentCounts` と、恒久装備の `gearUnlocked` は別のID集合です。モード・プリセット・掘削構成は#34へ分離します。

## 通貨と支出の内訳

- `runEarnedScore`: 現周回の累計SCORE。上限・突破・通常転生・ROOTの条件に使い、装備購入では減らしません。
- `scoreSpentThisRun`: 現周回の装備への支出累計（GameNumber）。
- `spendableScore = runEarnedScore - scoreSpentThisRun`: 利用可能SCORE。別残高は保存しません。
- `gearPurchasedThisRun`: 現周回で支払った装備IDの内訳。最大5件・重複不可。内訳は通貨残高ではなく、支出の正当性を検証する証跡です。

装備解禁では所持芋・ROOT結晶・通常ポイント・累計SCOREを変更しません。通常転生/ROOTは支出累計と内訳を0/空へ戻し、恒久装備と発見履歴を保持します。上限後も残高で解禁できますが、累計SCOREは上限のままで収穫・購入・DEPTHは再開しません。

支出合計はID定義順（価格の小さい順）で再計算し、購入順による巨大数の加算丸め差を避けます。支出が内訳の正規合計と厳密一致し、全内訳が解禁済み・ROOT/当周回段階の条件内で、支出が累計SCORE以内である必要があります。利用可能SCOREと購入後の正規合計を両方比較し、支払判定に許容誤差や借入を加えません。合計は最大32通りの不変値をキャッシュします。

ROOT前は名前・価格・効果を隠し、最後のSCORE帯で初回ROOTという条件だけ控えめに案内します。初回ROOT時にスコップ、以後はROOT回数を満たした当周回の各突破で発見します。ROOT前の最大発見段階4だけで全装備を予告公開しません。未到達品は非表示にし、直近の1件だけ「？？？」を表示します。

`permanent.gearDiscovered` は未購入品も保持します。通常転生後も名称は残り、当周回の再突破・ROOT条件・不足SCORE・解禁済みの理由を表示します。装備解禁は購入可能な現在段階でもあることを必要とします。`permanent.gearUnlocked` は全取得品の常時効果を表し、同じ装備の再支払を拒否します。

## 効果の合成と拡張境界

定義は `data/gear.ts` に価格・ROOT条件・発見段階・`source: 'gear'`・`passive` を集約します。評価は `core/gearProgress.ts` の `getGearMultiplier`、解禁は `core/gear.ts` に分けます。#34ではこの常時効果を維持したまま、モード由来の時間効果を別に合成する境界とします。

既存の生産式（台数倍率、設備ごとの研究とROOT後期倍率、基礎・設備合計とリンク追加、根源研究、通常/ROOT全体倍率）の**最後に装備全体倍率を乗算**します。基礎生産・全設備・リンク追加が対象です。購入増分の各変更成分とリンク増分にも同じ装備倍率を掛け、効率自動購入・生産キャッシュへ反映します。掘削・価格・ROOT報酬には作用しません。全5品は `1.05^4 × 1.10 ≈ 1.337056875` 倍です。

手動解禁の直前まで旧倍率で精算し、保存成功後に新倍率を公開します。放置中は既存の装備効果だけが有効で、装備解禁や突破は自動実行しません。状態と支出は同じ保存トランザクションに含め、容量不足・他タブ競合では新装備も支出も反映しません。

## 保存v13

周回へ `scoreSpentThisRun`（gn1文字列）と `gearPurchasedThisRun`（ID内訳）、恒久へ `gearUnlocked` / `gearDiscovered`（5種類のboolean）を追加します。未知ID・重複内訳・未解禁品の支出・不一致合計・負値/累計超過・不正フラグ・無権限/先行ROOT条件を拒否します。発見済みでない装備の取得も拒否します。

v1〜v12は累計SCORE・所持芋・通常/ROOT進行・研究・DEPTH・自動設定・保存時刻を保持し、支出0・内訳空・装備未購入を補完します。旧ROOT実行済み保存では、現在の段階とROOT回数で証明できる装備だけを発見します。過去の未記録のROOT後段階は推測しません。移行失敗時は原文を退避でき、再読込・インポートも同じ厳密検証を通します。[保存仕様](save.md)を参照してください。

## 正規ROOT1〜3周回での校正

初期状態から実コアで初回ROOTへ到達した状態を使い、1分自動・6h自動・12h手動の代表3経路をそれぞれ3周回します。初回結晶は原初の恵みに使い、以後の結晶は温存して装備の差を比較します。通常ポイントは保持した実ポイントだけで再取得します。装備は確認時だけ手動解禁し、放置中の購入を捏造しません。

| 確認・設備購入 | ROOT1回後→2回目 | ROOT2回後→3回目 | ROOT3回後→4回目 |
| --- | ---: | ---: | ---: |
| 1分・自動・随時装備解禁 | 3h58m | 3h41m | 3h30m |
| 1分・自動・各上限で装備解禁（対照） | 3h59m | 3h42m | 3h40m |
| 6h・自動・随時装備解禁 | 36h | 36h | 36h |
| 12h・手動・随時装備解禁 | 84h | 84h | 84h |

ROOT1回後の周回で3品、ROOT2回後にコンパスを追加して4品、ROOT3回後に根源コアを追加して5品です。装備倍率は順に1.157625 / 1.21550625 / 1.337056875。各ROOTリセットで支出0へ戻り、全取得品を保持しました。

提案価格・倍率を採用します。解禁済み装備を早く使う経路は上限まで待つ対照より速く、初回から全価格をまとめて払う必要はありません。ROOT回数と段階によって新装備を順に発見し、既存SCORE到達・ROOTは装備なしでも成立します。6h/12hは操作間隔のため到達確認時刻が同じでも、実到達時刻・生産能力・停止待ちには差があります。全プレイヤーの最適解や平均時間の保証ではありません。
