# 第3限界突破と設備連携（#29）

深層記憶（#37）を含むmain `7f45790` を起点に、段階3・SCORE上限1e15を追加しました。1e18・ROOT転生・DEPTH・装備は追加しません。

## 突破と継続

段階2でSCORE 1e12へ到達すると、採掘欄の「根脈接続解析」を確認して無料で実行できます。上限だけ1e15へ拡張し、SCORE・所持芋・全設備・スキル・研究ランク・支給履歴・ポイント・自動設定・計算端数を保持します。深層記憶の累計を増やさず、強化型の再購入制限も解除しません。自動購入は突破を実行しません。

接続権 `permanent.rootConnectionUnlocked` と恒久発見段階 `maxDiscoveredStage` を保存します。#45以降の通常転生では解析済みの段階2・設備0・周回研究0へ戻り、接続権と発見履歴は維持します。SCORE1e12へ再到達して手動で根脈接続を行えば無料で戻れます。同じROOT内で深層解析を繰り返さず、累計・保持枠・ポイント返還を増やしません。

同周回の二重実行・上限前実行を拒否します。セッションは旧速度で時間精算した後に候補を保存し、成功して初めて新しい段階と発見通知を公表します。取消・保存失敗・競合で段階や権限を失いません。1e15到達後は収穫・設備購入・研究購入/振り直しを停止し、通常転生と未実装の先の段階を案内します。

## 設備と連携

仮値を正規の成長経路で検証した結果、指定値を変更せず採用しました。いずれも段階3のみ購入可能で、台数マイルストーンはありません。

| ID | 設備 | 基礎価格 | 価格倍率 | 基礎生産/秒 |
| --- | --- | ---: | ---: | ---: |
| `rootRelay` | 根脈中継塔 | 2e13 | 1.25 | 5e8 |
| `coreChamber` | 芋核培養槽 | 2e14 | 1.30 | 5e9 |

`linked = min(floor(rootRelay / 2), coreChamber)` 組を所有数から導出し、各組が基礎生産を5e9/秒追加します。連携数や獲得フラグは保存しません。未接続の中継塔は `rootRelay - linked*2`、培養槽は `coreChamber - linked`。次の1組に不足する台数も表示します。

連携追加分に地層収穫学と全体の収穫倍率を乗算します。地脈共鳴は従来の地脈抽出機・芋濃縮炉だけが対象で、新2設備や連携分にはかけません。

`getEquipmentPurchaseGain(id, state)` は全所有数を受け、購入前後の総生産の差を返します。大きい不変の総量から小さい増分を失わないよう、変化する各成分の前後差と連携分の前後差を合計します。中継塔1→2、培養槽0→1、中継塔3→4による別設備の追加生産も効率へ反映します。費用は従来どおり各台ceilして合計し、MAXも単台連続購入と同じ状態になります。均等・効率・指定優先は従来の方針を維持します。

## 発見と表示

未発見の新2設備は、設備一覧・自動設定・優先順のoption・aria-labelを含めDOMから除外します。表示件数にも含めません。段階2では「次の発見: ？？？」を1件だけ予告し、必要SCOREと突破操作は明示します。根脈接続を初めて実行した時に名称・価格・効果を公開し、既存の控えめな進行通知で一度だけ発見を知らせます。

発見済みなら通常転生後も名称と説明を残し、「この周回は上限段階の再突破が必要」と示して購入をロックします。設定の個別フラグや優先順は保持し、非表示中のIDを並べ替えで消さないよう、可視IDの入替を元の順列へ反映します。

このIssueの公開制御対象は段階3の新設備です。既存段階1/2の設備・研究の公開方式を同じ規則へ広げる作業は、#5記載の後続範囲として残します。

v9は新設備2種の台数、全9設備の自動設定、新接続権・最大発見段階を保存します。金額の正規形文字列、深層記憶の累計・ロック、既存の24h精算・元テキスト退避・二重精算防止は維持します。

v1〜v8は従来の資産・権利・設定・履歴・時刻を検証して保持し、新設備0・接続権falseを追加します。v5の旧5設備、v6〜v8の旧7設備のフラグと重複のない優先順を先に検証し、新設備の個別設定ONを末尾へ追加します。全体OFFや既存OFFは維持します。不正な欠落を既定値で隠しません。

旧保存で研究権限trueなら深層解析の実行は確実なので最大発見段階2、現在段階1なら1、それ以外は0と復元します。心得を取得しただけでは未実施の突破を発見扱いしません。旧保存には段階3は存在せず、過去の不明な到達を捏造しません。
