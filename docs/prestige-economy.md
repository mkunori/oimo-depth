# SCORE帯・スキル上限・ポイント台帳（#46 / v16）

#47 / v17では [ROOT現行仕様](root-rebirth.md) により通常回数と生涯回数を分離し、ROOTの下位リセットと消失台帳計上を実装しました。以下の通常転生・解析ルールは継続し、ROOT保持に関する旧記載は現行仕様を優先します。

通常転生の報酬を実到達SCOREに応じて拡張し、深層解析で失ったランクの使用済みポイントを返還しません。#45の解析済み上限1e12の通常転生保持は継続します。ROOTによる通常スキル・ポイント全消去やROOT倍率の拡張は別Issueです。

1e5未満は転生不可。段階や残高から前借りしません。確認時に再精算し、予告したptと変われば再確認します。ROOTで通常ptを同時付与しません。1e18境界のテストではGameNumberの表現精度で確実に下回る値を使用し、購入判定へ許容誤差は入れません。

`rootCycleMaxUnlockedStage` は生涯の発見 `maxDiscoveredStage` と別に保存。各突破で最大値だけ更新し、通常転生と段階3への再突破では下げません。ROOTでは0へ戻します。今回のROOTは取得済みランクを消去しないため、以前のROOTから残るランクが新しい割当上限を超える場合は「保持」として効果を維持し、追加購入を止めます。検証にはROOT履歴と生涯の解放段階を必要とします。この例外で未購入ランクは購入できません。

費用は収穫[1,2,3,4,5,6,7]、割引[1,2,3,4,5]、蓄え[1,2,3,4,5,6]pt。収穫は各+50%でLv7が×4.5、割引は各10%でLv5が50%。心得・自動管理はLv1です。UIは現在の割当上限と、その範囲内の次ランクだけを表示し、未解放の価格・効果を出しません。

蓄えLv0〜6の開始芋は[0,50,100,500,5000,50000,500000]。購入時には支給せず、次の通常転生・ROOTで支給します。`runStartingImo` は実際の支給履歴であり、解析後の蓄え消失で回収しません。通常の既知支給値と、その時点までに取得可能だったROOT開始芋の和を検証します。ROOT強化を同じ周回の途中で増やした場合の旧支給額も受理します。

## 解析時のポイント消失

保持枠は解析累計1/2/3/4回で0/1/2/3種類のまま。保持対象は全取得ランクを残します。保持しないランクの累計費用を `pointsLostByDeepResearch` へ移し、未使用ptは変更しません。1〜3回目の強化型再購入禁止と、通常転生での解除は継続。4回目以降は全保持・消失0です。

## 台帳と移行

`lifetimePrestigePointsEarned = 現在ランクの累計費用 + unspentPoints + pointsLostByDeepResearch + pointsLostByRoot`

すべて非負の安全整数、合計も安全整数で厳密一致。総獲得ptは通常転生回数×1〜6の範囲で、解析履歴に対応する消失上限も検証します。ROOT消失は将来用の0として保存し、今回のコアでは非ゼロを拒否します。累計獲得・未使用pt・転生回数を安全範囲内で更新できない場合は保存前に失敗し、部分加算しません。

v1〜15は旧ランク上限3/2/2と旧総pt範囲を検証してから、現在ランクの累計費用＋未使用ptを総獲得へ、各消失を0へ初期化します。高SCOREの旧転生を新しい6pt等で再計算せず、返還済みptも回収しません。上限ランク拡張を旧形式へ紛れ込ませた保存は拒否します。ROOT0なら生涯最大解放を現ROOTの最大とでき、ROOT後は現在段階・解析完了で証明できる範囲だけを補完します。旧ランクは初期上限内なのでこの推定で資産は失いません。

## 校正と重点検証

提示された費用・効果を採用。初回解析→1e12は従来と同じ1分自動51分、6h自動6時間、12h手動24時間。初回ROOTも1分自動約49.38時間、6h自動126時間、12h手動276時間で、今回の非返還で初回進行を追加で遅らせません。解析直後の未使用ptだけが減り、その後の通常転生・ROOT後の再取得予算に差が出ます。

既存の代表3経路を通常転生後3周回へ延長。1e18の6ptと後続1e12の4ptだけを使い、収穫・蓄え・割引に投資します。実支給は0→100→500芋（12h手動は0→50→500）。1分自動の各周回は約58.83h/58.82h/47.05h、6h自動は各54h、12h手動は各48h。既存の効率購入は高額な濃縮炉を待つため、短時間周回の最適性は保証しません。蓄えLv6の50万芋、ROOT後の高ランク保持、次解析で36pt消失しても実支給を回収しないことは本番操作を使う重点テストで検証します。
